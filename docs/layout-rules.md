# 학습 플레이어 화면(레이아웃) 규칙

운영자(인호)가 화면을 보고 결정한 규칙을 모아 둔다. 새 화면/템플릿을 만들 때 지키고, 푸시 전에 `tools/layout-qa` 를 돌린다.
(자동 검사 가능한 규칙은 `[자동]`, 눈으로 봐야 하는 규칙은 `[눈]`)

## 공통
- [자동] 어떤 화면 폭(1280·1024·800)에서도 글·버튼·그림이 화면 밖으로 나가거나 서로 겹치지 않는다. 긴 문장은 줄바꿈한다.
- [자동] 선택 요소(삽화·그림·보조 글 등)가 없는 문항은 있을 때와 레이아웃이 깨지지 않고, 수정 전 화면과 같아야 한다(`--compare`).
- [눈] 활동 시작 시 이전 화면(학습 흐름 목록)의 잔상이 보이면 안 된다. 머리줄에 "활동 n/N" 칩은 두지 않는다.
- [눈] 선택 요소는 "있으면 쓰고 없으면 아무 영향 없음"으로 만든다(optional).
- [눈] 같은 모양의 화면은 같은 배치 규칙을 쓴다(새 CSS를 덧붙이기 전에 기존 규칙 재사용 가능한지 먼저 본다).

## 그림(삽화·상품 그림)
- 글 상자가 있는 화면(Model Writing 보기 등): 그림은 **상자 안 오른쪽**, 글과 겹치지 않게.
- 상자 없는 글 화면(Model Text): 그림은 **영어 본문 왼쪽**, 제목 줄을 뺀 **글줄 높이의 세로 가운데**.
- 상품 그림 + 가격표(Role Play·Look & Speak·대화 완성(그림)·Look & Talk): 가격표는 **상품 그림 바로 오른쪽 옆, 박스 안**. 한 장의 그림처럼 보여야 한다. 라벨(단어)은 그림 왼쪽 위.
- 발표(Presentation)처럼 영상 화면이 있는 곳에는 삽화를 넣지 않는다.

## 버튼·도구줄
- Model Text 의 듣기 / 따라 읽기 버튼은 **영어 본문 왼쪽 줄**에서 시작하고, 본문·해설 사이 세로선을 넘지 않는다.
- Listen & Choose (Number): 선택지는 **한 줄**(4개여도). 듣기 막대와 선택지 사이 간격은 기본의 3배.

## 템플릿별
- Complete the Dialogue (Text Cue): 라운드 있는 박스(`.nv-dfw .nv-bl-box`, 1em).
- Listen & Write (Blank): 한 문항 = 대화 하나 + 한 줄 질문, 음원은 1개. 두 줄 캡슐은 화면에서 정리해 한 덩어리로.
- Model Writing (Free): 상품 이름은 상단 칸 + 3번째 줄 빈칸에 학생이 씀. 문항 하나는 단수 틀(this/is/It's), 하나는 복수 틀(these/are/They're). 그림 없음.
- 학습 흐름 머리줄 "1차시"의 숫자는 글자와 세로 가운데 정렬(`.mx-dl-h .mx-lnum`).

## 관리자
- 문항 목록 스크롤 시 제목 줄(sticky)과 목록이 겹쳐 보이지 않는다(`.mx-scroll th`).
